# Design and motion references

The implementation adapts reference ideas with Kevin's real content and supplied photos. It is locally authored.

| Source | Idea | Application |
| --- | --- | --- |
| [Aceternity — Navbar Pill](https://ui.aceternity.com/blocks/navbars/navbar-pill) | Group navigation and distinguish the active page. | Pill navigation and all five routes; an accessible mobile dialog. Kevin requested a single icon for the direct theme toggle. |
| [Aceternity — Minimal Hero](https://ui.aceternity.com/blocks/hero-sections/minimal-hero-with-huge-interactions) | Clear personal hierarchy and actions. | Large name and role, two actions, and a real portrait that changes with the theme. |
| [Aceternity — Accordion and Image](https://ui.aceternity.com/blocks/feature-sections/features-with-accordion-and-image) | Tie a capability to a visual example. | Three disclosures and matching project screenshot crossfades. |
| [Aceternity — Centered CTA](https://ui.aceternity.com/blocks/cta-sections/cta-with-centered-text) | Focus the contact invitation. | Centered message, email action, visible address and copy feedback. |
| [Aceternity — Footer layouts](https://ui.aceternity.com/blocks/footers) | Organize navigation and social links. | Name, Explore and Elsewhere groups; preserved CV and optional audio. |
| [21st.dev — Portfolio Hero](https://21st.dev/@waleedkibhen/components/portfolio-hero) | Personal typography and image-led identity. | A personal introduction and clear project/CV actions. |
| [21st.dev — Portfolio Gallery](https://21st.dev/@isaiahbjork/components/portfolio-gallery) | Make the artifacts lead. | Real screens in three selected-project cards. |
| [Anime.js — stagger](https://animejs.com/documentation/utilities/stagger/) | Sequence related elements. | Hero reading order with 75ms offsets, implemented with Motion for React. |
| [Motion — reduced motion](https://motion.dev/docs/react-use-reduced-motion) | Respect motion preferences. | Reduced-motion handling for hero, fan, folder reveal and image transitions. |

Kevin's screenshots supplied the fanned-card and folder-archive directions. Exactly three projects appear on the landing page; all four appear in the archive. His color and black-and-white portraits replace the old image. Theme changes trigger the photo transition without a continuous GIF loop.

UI Skills CLI 0.2.4: Baseline UI, Better Colors, and Animation Systems guided primitive choice, semantic theme roles, measured contrast, and compositor-based motion.
